# 문서 인덱스

작업과 관련된 문서만 골라 읽는다. 현재 동작의 기준은 소스이며, 문서는 파일 간 연결 지점을 찾는 데 사용한다.

## 현재 구현 참고

- 새 백엔드 기능의 계층과 등록 지점을 확인할 때: [기능 구조 참고](../tlab-boilerplate/docs/feature-structure.md)
- 역할·퍼미션 모델과 권한 검사 흐름을 확인할 때: [RBAC 구조와 권한 코드](../tlab-boilerplate/docs/rbac.md)
- UI 화면과 API 연결 지점을 확인할 때: [UI README](../tlab-boilerplate-ui/README.md)
- 로그인 화면, 쿠키, 현재 사용자 조회 흐름을 확인할 때: [로그인 상태 관리](../tlab-boilerplate-ui/docs/explain/login-auth-flow.md)

다음 문서는 구현 당시의 계획 기록이다. 현재 구현의 근거로 사용하지 않고, 과거 설계 의도를 확인할 때만 참고한다.

- [RBAC 인증 연계 구현안](../tlab-boilerplate/docs/plan/rbac-integration-plan.md)
- [JWT 구현안](../tlab-boilerplate/docs/plan/jwt-implementation-plan.md)
